Домашняя работа 3

Взял тесты на го из второй лабы и добавил запуск через докер. В них уже были проверки постов, авторизации и graphql.

Для запуска нужен работающий докер и интернет. Из папки проекта сначала собираем образ:

docker build -t api-test .

Потом запускаем:

docker run --rm api-test

Тесты запускаются сами, результат видно в терминале, у меня все прошли :)

Потом специально подставил нерабочий адрес graphql:

docker run --rm -e GRAPHQL_API_URL=http://127.0.0.1:1/graphql api-test

Тесты упали, контейнер вернул код 1. То есть по коду завершения понятно, прошел запуск или нет.

Для ci добавил .github/workflows/ci.yml. После пуша github actions собирает образ и запускает в нем тесты. Если сборка или тесты падают, джоба тоже падает. Запуск по pull request и вручную тоже добавил.

Репозиторий лабы: [hw3-testing](https://github.com/dulfi4/hw3-testing). Результаты ci будут во вкладке Actions.

Логи сборки и запусков сохранил в evidence.
